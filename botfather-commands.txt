start - Welcome message with live stats & quick command reference.
help - Lists every command with description & usage.
pending - List all unanswered questions waiting for your reply.
answer - Answer a question. Reply to a bot message or use /answer <id> <text>
edit - Edit answer to a question. Usage: /edit <id> then send new text.
recent - Last 5 answered questions with response times.
all - Browse every question (paginated). Shows state, preview & ID.
get - Full detail card for a question. Usage: /get <id>
search - Search Q&A by keyword. Matches question, answer & name. Usage: /search <text>
lookup - Interactive ID lookup mode. Paste an ID to get details. /cancel to exit.
pin - Pin question to top of site AMA. Usage: /pin <id>
unpin - Remove pin from question. Returns to normal sort. Usage: /unpin <id>
pinned - List all currently pinned questions with previews.
delete - Delete a single question. Confirms first. Usage: /delete <id>
deleteall - Permanently delete ALL questions. Type-token confirm; /undo can restore.
undo - Reverse the last delete or dismiss (single or bulk).
queue - Answer pending questions inline: each as a card with Answer/Dismiss/AI-draft.
draft - AI-generate an answer suggestion, then preview. Usage: /draft <id>
improve - AI-improve an existing answer, then preview. Usage: /improve <id>
shorten - AI-shorten an existing answer, then preview. Usage: /shorten <id>
expand - AI-expand an existing answer, then preview. Usage: /expand <id>
publish - Publish a saved draft answer to the site. Usage: /publish <id>
drafts - List unpublished draft answers (with any scheduled times).
schedule - Auto-publish a draft later. Usage: /schedule <id> +2h | ISO time
templates - List saved reply templates and their usage.
addtemplate - Save a reply template. Usage: /addtemplate name | template text
usetemplate - Load a template as a preview answer. Usage: /usetemplate name <id>
deltemplate - Delete a saved template. Usage: /deltemplate name
trends - Activity trend + response-time analytics.
top - Most upvoted / reacted answers.
dismiss - Hide a question from your site. Data preserved. Usage: /dismiss <id>
dismissall - Hide ALL active questions from your site at once. Confirms first. Retrieve later.
dismissed - Browse all dismissed (hidden) questions with state info.
retrieve - Restore one dismissed question. Usage: /retrieve <id>
retrieveall - Restore ALL dismissed questions at once. Confirms first.
export - Export all Q&A. Tap to pick Text / JSON / CSV, or use /export json|csv.
stats - Full dashboard: totals, pinned count, avg response time & top question.
refresh - Combined view: unanswered + dismissed. Everything needing attention.
digest - 7-day AMA activity summary with suggested next action.
inbox - Smart priority inbox ranked by urgency and value.
topics - Keyword-based topic breakdown of all AMA questions.
quality - Finds published answers that may need improvement.
spotlight - Feature one answered AMA. Usage: /spotlight <id>
featured - Show the currently featured AMA.
health - Check Telegram, Firestore, webhook and database status.
cancel - Abort active session (answer, edit, lookup). Returns to normal mode.
unspotlight - Clear the currently featured AMA.
topic - Set manual topic for a question. Usage: /topic <id> <topic>
topicof - Show active/manual/auto topic for a question. Usage: /topicof <id>
cleartopic - Remove manual topic and return to auto topic. Usage: /cleartopic <id>
retopic - Recompute automatic topic for one question. Usage: /retopic <id>
retopics - Recompute automatic topics for all non-manual questions.
